## Summary

Restored `!row.disabled` on thumbnail hydration so a blocked row's ad_id is
never posted to `/file/video/ad/info/`. The binary split now runs only on
TikTok's unacceptable-`video_ids` shape; a 401, 429 or transport error
retries the same chunk once, then abandons hydration without marking
`thumbnailError`. `originOf` is pinned as `some` — a stem group is badged
when any copy is unjoined — with a two-copy fixture that fails under
`every`. Rebased onto current `main`.

## Scope / files

- `lib/tiktok/import/picker.ts` — restore `!row.disabled`; split only on

- `lib/tiktok/import/map.ts` — `originOf` docblock (`some`, not `every`).
- Tests: blocked Ironworks carousel rows ask for zero ids; 401/429/
