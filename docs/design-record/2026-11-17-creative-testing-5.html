One Tests campaign per show, every test its own ad set

This record carries Matas's rules of 17 Nov for test campaigns, and the ad set names ruled on #1297.

  • One campaign: one {code} · Tests campaign per show.
  • One ad set per test: every test is its own ad set, with its own budget.
  • Created live.

It replaces TT1's "one Advantage+ ad set per format (Video and Statics)" and the "created paused" of CT6 and PR D's first build. Everything else in TT1 stands: the Advantage+ ad set, one creative test at a time, and Test 3 against the current best ad. TF1–TF4, TT4–TT7, AU1–AU4 and the rest of CT1–CT12 stand. The example dates are invented.

Rulings

#Ruling
TT8 · One Tests campaign per show
  • One per show: {code} · Tests, objective Sales, on the show's ad account. Every test the show runs goes into it as an ad set: the creative tests (Video, Statics), A/B copy tests and artist-card tests.
  • Found, never made twice. A test finds the campaign by its exact name on the show's ad account and reuses it. Only when there's none, or the one there is deleted or archived, does it make a new one.
  • No campaign budget, ever. Each ad set carries its own budget, so Meta can't move money from one test to another. A campaign that has a budget is refused (TT11).
  • The 17 Nov round stays as built (Matas). {code} · AB copy test and {code} · Artist cards test are left as they are: not renamed, not moved, not reused. New A/B copy and artist-card tests go into {code} · Tests.
  • Never main spend. The spend of {code} · Tests and of the two round campaigns never counts as a main campaign's. That covers TF1's current daily spend, the best ad CT copies from, and the refresh's moves.
TT9 · Every test its own ad set, made live
  • One ad set per test, with its own daily budget:
    • creative tests are sized by TF1;
    • A/B copy and artist-card tests keep the budget their own flows set today. This record doesn't change it.
  • Four days. Each ad set ends at 23:59 London on the fourth day after the London day it starts. TF2's read at day 4 is the last one.
  • Created live (Matas, 17 Nov): the campaign, the ad set and its ads go in ACTIVE.
    • Approving the test is the approval, as an add goes in live on the refresh panel.
    • The create gate (CREATIVE_TESTS_CREATE_ENABLED) and "Only Matas can approve a test's variants." stand.
    • The plan still holds TF1's four days against R5's 20 % cap before anything is made.
  • One creative test at a time stands ("Waiting for Test {n}"). A/B copy and artist-card tests don't wait on it, and it doesn't wait on them.
  • The app follows its own ad sets by their stored ids (launched_ad_sets), never by name. The names in TT10 are for people reading Ads Manager.
TT10 · Ad set names

"{code} · Tests · {kind} · {d Mon}"

  • {kind}: Video or Statics for a creative test, by its format. AB copy for an A/B copy test. Artist cards for an artist-card test.
  • {d Mon} is the London day the ad set is made: the day without a leading zero and the three-letter month, as everywhere else ("17 Nov", "4 Dec").
  • A same-day repeat of the same kind adds " · 2", then " · 3". The first one has no number.
  • Ads inside keep their names: the render's file name, or "{ad set name} · {variant}".
