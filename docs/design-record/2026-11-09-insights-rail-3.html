R20 Best copy shapesIn campaign creation (IR4) Best lines and Proven elsewhere are replaced by one section, Best copy shapes, first in the rail. A row is a feature value from copy_features at the drawer's stage and the chosen scope: its label (R23), a bar by stored shrunk index with the baseline tick at 1.00, the value "0.75 · 25% under", and a sub-line "3 shows · 27 ads". R6–R8 and R13 apply (olive ≤ 0.95 ok/strong, brick ≥ 1.10, four rows, "+n more", result sentence, confidence line). Thin is under 2 shows or under 10 ads (Invented); thin rows read "Not enough data yet: n shows". The confidence line reads {strong|ok} · {ads}+ ads · {shows}+ shows · 90 days · {scope} with the minimum of the drawn rows. The result sentence names the shape: "4+ line bodies cost 25% less than usual." Scope defaults as R5; at All clients the 🔒 line shows.
R21 One population, one findingRows whose shows and ads sets are identical are one population read several ways, and draw as one line: the strongest-named facet as the label, the others listed after it in ink-3 — "4+ lines · promoter voice · dated · a price", one bar, one value, one sub-line. The collapsed row counts once toward the four and once in "+n more". Rows that share some ads but not the whole set stay separate. Identity is on the ads that fed the row, never on counts alone: two features with 27 ads each are not the same 27 unless they are. copy_features stores counts only (migration 213), so the job writes ads_hash — sha256 of the sorted Meta ad ids behind the row — and equal hashes are one population (H18).
R22 Verbatim linesUnder the shapes, a second section Copy lines stays empty with one sentence while copy_performance has no proven line: "No line has run in two shows yet. Lines appear here, as chips you can drop into the copy, once one does." The writer's proven chips (pass 2 B3a) carry the same sentence in their place. When a line qualifies (won at 2+ events), the section fills as issue 1's IR4 described, with Use line.
R23 WordsFeature keys never show (rule 5). The label map ships with the section: opener → "Opener: {value}" · cta_kind → "{value} CTA" · scarcity_kind → "{value} scarcity" · length_band → "{band} body" · emoji_band → "{band} emoji" · lineup_list → "lineup listed" / "no lineup" · date → "dated" / "undated" · price → "a price" / "no price" · line_count → "{n}+ lines". Voice is a facet of the opener's source: "promoter voice" / "artist voice". A shape's one action is Use shape only where it maps to a generator control (artist voice → Angle "Artist, first person"; lineup listed → Angle "Lineup"); otherwise none. It pre-sets, never generates.
