The Off/Pixel deck — the rules, by family, with the record each came from

The single document the three-way split works from: the design thread owns the rules and judges renders, Claude Design draws, Cursor builds. One page per rule family; every rule carries its id and the record it came from. Nothing is ruled here. The deck cites. Where a row is condensed from a long ruling, the record's own text rules; where two records disagree, the row is on the Open rulings page, not resolved. Records never change after merge, so a page here changes only when a new record lands and a new issue of the deck is cut.

How to cite

Point at a rule by its id and family — rule 6, R13, A5', O11, Q4 — and at a component by its name in page 4. A build prompt names the frame and the component and says only what differs. If a screen needs something no component covers, stop and ask for a frame; don't invent one in words (design-rules.md, "How to use this in a prompt").

What the deck is not

  • Not a record. It rules nothing; it has no frames; it is never the acceptance for a build. The acceptance is the record the rule came from.
  • Not the latest word on live state (campaign data, what's built, what's merged). That lives in the north star (issue 2) and the PRs.
  • Not verbatim everywhere. Long rulings are condensed; the record's row rules where wording differs. Short rules and every number are as written.

13 The locked caption styleCaptions on UGC use the locked caption style. TikTok Sans, weight 400, width 120, white fill with a black stroke outside the letters, no shadow, no box. One component everywhere a caption sits on a clip. Size 5.1 % of frame width, line height 1.05, stroke ≈ 1 % W, lines wrap at ≈ 80 % W. Copy that's too long is shortened, never set smaller; if it can't be shortened, it's flagged and can't be approved. open · page 11 the "never set smaller" clause against overlay O3 / O8.rules 14 · pass-3
