Creative testing issue 7: the end day's read decides

From #1346, the daily test read. TT9 ends a test ad set at 23:59 London on its fourth day. The build took TF2's "last read at day 4" as the first read at 96 h or more, which is the next morning's 08:00 read. Any extension TF6 writes then lands after the ad set has ended, so it's off overnight. This record moves the call onto the end day, so an extension is written before the ad set stops.

What this amends: when TF2's day-4 read, and TF6's day-8 and day-12 reads, are made.

What stands: TF1–TF4, TF5–TF8 (#1341), TT8–TT11, VP1–VP10 (#1339), R5's cap and #1297's cap sentence. Every figure, line and frame stands, TF-D included. It applies to every test TF2 calls.

The fallback for a missed end-day read is invented.

Ruling

#Ruling
TF9 · The end day's read decides
  • The end day is the London day of the ad set's 23:59 end: day 4 (TT9), then day 8 and day 12 after an extension (TF6).
  • Its read is that day's 08:00 London read, after the insights restate, however many hours the ad set has run. It is not the first read at 96 h. It covers everything up to the end of the day before.
  • That read makes TF6's call, and any write goes through the Tests path (TT8–TT9), behind the same gate:
    • A winner (TF2's read and the benchmark, TF5): "Ready to call", as now. The ad set runs to its 23:59 end.
    • All above the benchmark, and the hold fits the cap: the extension. The end moves to 23:59 London four days later, written that morning, so the ad set never stops. The line is "Extended to {d Mon}: …" (TF7).
    • All above the benchmark, and the hold doesn't fit, or the day-8 rule says stop: the stop. The ad set is paused at that read, so the end day's remaining budget isn't spent, and TF6's stop line shows.
    • No benchmark (TF5) and no winner: nothing is written. The ad set runs to its 23:59 end.
  • The end day's own hours still count:
    • after an extension, the next day's read includes them as usual;
    • when the ad set ends without one, the read the morning after it ends is its last. It reads all the spend and can still find a winner. Only when it finds none does the test read "No clear winner by day 4". With no benchmark there's no extension, so this is always day 4.
  • A missed end-day read. If the end day's read hasn't run by 23:00 London, nothing is written that day. The next morning's read then decides as the build does now, and an extension then restarts the ad set after its night off.
  • Never:
    • two writes for one end day (the ledger's one row per write stands);
    • a write from a read that doesn't cover the whole of the day before;
    • a pause or an extension on any day other than an end day.

Example

P26-BDAY's Test 2 · Track pair · Get Hard (#1341's example). It was made on 18 Nov, so day 4 ends at 23:59 on 22 Nov.

  • 22 Nov, 08:00: the read covers up to the end of 21 Nov. Both variants are above £3.00, and the £4.00 hold fits the cap. The end moves to 23:59 on 26 Nov that morning, and the panel reads "Extended to 26 Nov: both above the show's £3.00 per checkout". The ad set keeps running through 22 Nov and on.
  • 26 Nov, 08:00: the day-8 read covers up to the end of 25 Nov. Neither variant has improved, so the ad set is paused at that read with "Stopped: both above the show's £3.00 per checkout".

TF-D's figures and words stand as #1341 draws them. No frame is added or re-shot.

Hand-back

PieceBuild
HT4 · The end-day read (#1346)
  • The decision runs at the 08:00 London read on the ad set's end day (day 4, 8 or 12), not at the first read at 96 h.
  • Extend or pause is written that morning, through the existing write path, one ledger row per write, behind the killswitches.
  • When no write is made, the morning-after read is the test's last read and can still find a winner.
  • No write after 23:00 London on the end day. A missed day falls back to the next morning's read.
  • Unit tests:
    • an extension written on the end day, with no gap in the ad set's run;
    • a stop paused on the end day;
    • a no-benchmark test with no write, then a winner found the morning after;
    • the same with no winner, reading "No clear winner by day 4";
    • a read that doesn't cover the day before, making no write;
    • a missed end day falling back to the next morning;
    • a second run on the same end day, making no second write.

Acceptance

  • No night off: an extended ad set's end date is moved before 23:59 on its end day, and Meta shows no gap in delivery.
  • A stop: a stop pauses at the end day's 08:00 read, with TF6's line.
  • No write: a test that ends without a write still gets its last read the morning after.
  • Words and frames: every line and frame reads as #1341 rules it.

Invented here

  • The 23:00 London cut-off, and the fallback to the next morning's read.
  • The morning-after last read for a test that ends without a write.

Open for Matas

None. A stop pauses at the end day's read, because Matas's rule is to stop the test and pause its ad set. The end day's last hours aren't run for a test that's already lost to the show.
